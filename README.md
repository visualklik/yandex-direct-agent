# Yandex Direct Agent

Четыре скилла для Claude Code: стратег, специалист, аналитик и аудитор. Справка Яндекс Директа — общая база знаний.

Надстройка над [visualklik/yandex-direct-docs](https://github.com/visualklik/yandex-direct-docs) — 509 статей официальной справки в Markdown. Сама справка сюда не копируется, подключается отдельно (см. установку).

## Что внутри

| Скилл | Что делает |
|---|---|
| **marketing-strategy** | Стратег: бриф из сайта и аккаунта, проверка спроса фактами через API, персоны, УТП по Котлеру, выбор каналов, бюджет по фазам «тест — оптимизация — масштаб», KPI с триггерами. Кампании не создаёт — готовит вход для остальных |
| **yandex-direct** | Специалист: собирает бриф, проектирует структуру кампании (Поиск/РСЯ/ЕПК, Мастер кампаний, Товарная, медийка, приложения, Telegram Ads), подбирает стратегию, ключи и минус-слова, пишет объявления в лимитах и **создаёт кампанию** — через XLS/XLSX или браузер |
| **yandex-direct-analyst** | Аналитик: разбирает выгрузки Мастера отчётов, считает CTR/CPC/CPA/CR/ДРР/ROI, проверяет статистическую значимость, находит сливающие бюджет срезы, сравнивает периоды и эксперименты |
| **yandex-direct-audit** | Аудитор: снимает слепок настроек через API, прогоняет реестр проверок со статусами и баллом (грейд A–F), ищет аномальные дни, проверяет доступность посадочных, разбирает площадки РСЯ по порогу статзначимости и собирает визуальный HTML-отчёт с планом правок |

Плюс четыре субагента в `.claude/agents/` — стратег, консультант по справке, аналитик и аудитор, работающие в своём контексте.

```

├── skills/
│   ├── marketing-strategy/

│   │                             # бюджет, KPI, передача + demand_probe.py
│   ├── yandex-direct/
│   │   ├── SKILL.md              # режимы, workflow, правила безопасности
│   │   ├── action/               # XLS-генерация, браузерный workflow, чеклист
│   │   ├── updates/              # механики свежее выгрузки справки
│   │   └── docs/                 # ← подключается отдельно, см. установку
│   ├── yandex-direct-analyst/

│   │   └── analysis/             # метрики, отчёты, диагностика, loader.py
```

## Установка

```bash
git clone https://github.com/visualklik/yandex-direct-agent
cd yandex-direct-agent

# База знаний: 509 статей справки
git clone https://github.com/visualklik/yandex-direct-docs \
  .claude/skills/yandex-direct/docs

# Аналитику и аудитору справка доступна по симлинку
ln -s ../yandex-direct/docs .claude/skills/yandex-direct-analyst/docs
ln -s ../yandex-direct/docs .claude/skills/yandex-direct-audit/docs
```

Запустить Claude Code в этой папке — скиллы подхватятся автоматически.

Для разбора выгрузок нужны `pandas` и `openpyxl`:

```bash
pip install pandas openpyxl
```

## Особенности

- **Правила безопасности.** Реклама тратит реальные деньги: любой необратимый шаг — публикация, отправка на модерацию, пополнение счёта — только после явного подтверждения. Логин, пароль и платёжные данные вводит пользователь сам, CAPTCHA скилл не решает.
- **Только факты из справки.** Ответы с цитатой, путём к файлу и ссылкой на первоисточник; чего нет в базе — так и говорится.
- **Статистическая значимость.** Аналитик не делает выводов по одной-двум конверсиям: есть таблица погрешности и пороги, после которых «ноль конверсий» становится сигналом.
- **Аудит по факту.** Аудитор читает настройки через API, а не полагается на память: каждая находка — с текущим значением настройки и списком объектов. Проверенные имена полей API и грабли (лимит 10 кампаний на запрос, `Levels` внутри `SelectionCriteria`, `v501` без `TrackingParams`) описаны в `audit/api-collect.md`.
- **`updates/`** — механики, появившиеся после выгрузки справки (перенос остатка недельного бюджета, адаптация бюджета, окно списания 21 день при оплате за конверсии, приоритет корректировок).

- [ai-hub-open/marketing-strategist](https://github.com/ai-hub-open/marketing-strategist) — источник структуры стратегического скилла: пошаговый процесс с гейтами подтверждения, разделение «УТП / довесок / уточнение» по Котлеру, матрица выбора каналов, фазы бюджета «тест — оптимизация — масштаб», KPI как триггеры действий. Реализация своя: спрос проверяется через API Директа, отраслевые бенчмарки не используются, бюджет считается от порога обучения автостратегии.

Контент справки принадлежит Яндексу. Скиллы и конспекты — собственная работа.

## Что взято из yandex-direct-skill

Код не заимствован — только подходы, переписанные под наш API-first аудит.

| Взято | Как реализовано у нас |
|---|---|
| Реестр проверок с идентификаторами и категориями | `audit/checks.py`: константа `CHECKS`, у каждой проверки id, категория, серьёзность и признак быстрой починки |
| Формула балла с весами и грейдами A–F | `audit/scoring.md`; **статус N/A исключается из знаменателя** — неприменимая проверка не занижает оценку |
| Статусы PASS / WARNING / FAIL / N/A | те же четыре, но выставляются кодом по слепку API, а не суждением |
| Идея Quick Wins | флаг `quick` в реестре, отдельный блок над планом правок в дашборде |
| Блок комплаенса | `audit/compliance.md`, переписан по `docs/technologies-and-services/ad-labelingl.md` и `docs/moderation/` |
| Проверки: продуктивность фраз, размер групп, кампании-зомби, число быстрых ссылок, широкоформатные изображения | `KEY01`, `STR02`, `STR03`, `AD04`, `AD06` |

**Что сознательно не взято:**

- **Бенчмарки по нишам** (CTR/CPC/CVR/CPA) — приведены без источника, выборки и периода. У нас норма считается по самому аккаунту: медиана дневных рядов и KPI бизнеса.
- **Скрипты сбора** — в них три ошибки, на которые мы уже натыкались: `CampaignIds` шлются пачкой больше десяти, `sitelinks.get` и `negativekeywordsharedsets.get` вызываются без обязательного `Ids`, объявления читаются только через `TextAdFieldNames` (комбинаторные отдадут один заголовок вместо всех).
- **Спецификации изображений** — расходятся со справкой: там жёсткий квадрат 1024×1024 вместо диапазона 1:1…4:3 от 450 px, 16:9 только 1080×607 вместо диапазона до 5000×2812, забыт GIF и лимит 4 МБ в Мастере кампаний. Наш разбор — `yandex-direct/action/rsya-creatives.md`, каждая цифра со ссылкой на статью справки.
- **CRUD-команды** (`create`, `keywords`, `budget`) — это работа скилла `yandex-direct`, аудитор ничего не меняет.
