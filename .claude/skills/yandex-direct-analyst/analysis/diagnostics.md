# Диагностика: симптом → гипотеза → проверка → правка

Правки исполняет скилл `yandex-direct` (XLS/браузер) после «да» пользователя. Здесь — только вердикт и рекомендация. Полный чеклист эффективности — `docs/efficiency/check-list.md`, `docs/efficiency/improve-efficiency.md`.

Общий порядок: **проверить учёт → проверить объём → разложить CPA на CPC и CR → найти срез-виновник → предложить правку с ожидаемым эффектом.**

## 0. Сначала — не сломан ли учёт

Прежде чем объяснять просадку, исключить артефакт данных:
- Счётчик Метрики на всех страницах, привязан к кампании; цели не удалены/не переименованы; автоцели.
- Не менялась ли модель атрибуции или цель в отчёте/в стратегии.
- Не режет ли фильтр отчёта часть данных; не смешаны ли Поиск и Сети.
- Не последние ли это дни (конверсии дозаписываются).
- Правки на сайте: редизайн формы, новый домен, сломанный тег, CMP-баннер.
Признак артефакта: клики и расход стабильны, конверсии обрываются резко «в ноль» с конкретной даты.

## 1. Мало показов / нет трафика

| Гипотеза | Проверка | Правка |
|----------|----------|--------|
| Кампания/группы остановлены, деньги кончились | статус, баланс | пополнение — сам пользователь |
| Не прошла модерация | статус объявлений | `docs/moderation/` |
| Узкая семантика, много минус-слов | число фраз, длина минус-списка | расширить ключи, снять лишние минус-слова и спецоператоры |
| Низкая ставка / низкий бюджет стратегии | доля показов, средняя ставка | поднять недельный бюджет/целевой CPA |
| Жёсткое гео/расписание/корректировки −100% | настройки кампании | ослабить ограничения |
| Автотаргетинг выключен | настройки группы | включить (в ЕПК обязателен ≥1 категория) |

## 2. Клики есть, конверсий нет

| Гипотеза | Проверка | Правка |
|----------|----------|--------|
| Нецелевые запросы | «Поисковые запросы»: доля мусора в кликах | минус-фразы, уточнить операторами, отключить категорию автотаргетинга |
| Посадочная не соответствует запросу | срез фраза × страница перехода, отказы в Метрике | своя посадочная под кластер |
| Сайт: скорость, мобильная версия, сложная форма | Метрика (Вебвизор, отказы, доля моб.) | правки сайта; при плохой моб. версии — корректировка по устройствам |
| Цель считает не то (микро- вместо макроцели) | определение цели | пересобрать цели по воронке |
| Звонки/офлайн не учитываются | есть ли коллтрекинг, офлайн-конверсии | `docs/statistics/conversions.md`, `docs/strategies/offline-conversions.md` |
| Скликивание | антифрод, аномальные площадки/IP | `docs/technologies-and-services/antifraud.md`; ручное «наказание» площадок обычно бессмысленно |
| Просто мало данных | число кликов vs 3 / ожидаемый CR | ждать, не резать |

## 3. CPA вырос

Сначала: `CPA = CPC / CR` — что сдвинулось.

**Вырос CPC:**
- конкурентный аукцион (сезон, новый игрок) → сверить динамику CPC по дням и доле показов;
- поднят целевой CPA/бюджет стратегии → сама стратегия закупает дороже;
- сместился микс: больше дорогого Поиска, меньше дешёвой РСЯ → срез по типу площадки;
- корректировки ставок вверх;
- упал CTR на Поиске → выше цена входа (объявления устарели, конкуренты переписали свои).

**Упал CR:**
- новые нецелевые источники трафика (расширение автотаргетинга, новые площадки, семантическое соответствие) → срез по типу соответствия/условию показа;
- сайт/оффер/цена изменились, ушёл товар из наличия;
- сезонность спроса;
- сменилась структура аудитории (больше мобильных, другое гео).

**Правка**: резать конкретный виновный срез (фраза, площадка, гео, устройство, время), а не «поднять/опустить всё». Если стратегия автоматическая — двигать целевой CPA/ДРР шагами ≤20–30% и ждать перестройки, а не менять тип стратегии на ходу.

## 4. Расход растёт, конверсии — нет

- Разложить расход по срезам, найти строки с расходом ≥ N × целевой CPA и 0 конверсий (статзначимо) → отключить/минусовать.
- Проверить обучение стратегии (свежая кампания, недавние правки).
- Проверить дубли: одни и те же запросы в нескольких кампаниях конкурируют между собой.
- Рассмотреть оплату за конверсии вместо кликов (`docs/strategies/average-cpa.md`).

## 5. Конверсии подешевели, но выручка упала

- Оптимизация ушла в дешёвые микроконверсии → сверить цели: какая цель реально деньги.
- Смотреть Доход/ДРР/ROI, а не CPA (`docs/statistics/profit-and-value.md`).
- Проверить средний чек по каналу и долю брендового трафика (бренд дёшев и маскирует убыточный небренд).

## 6. Цифры Директа ≠ цифры Метрики/CRM

Причины по частоте: разные модели атрибуции; разные цели; клики vs визиты (роботы, не догрузился счётчик, редиректы, отказ от согласия); часовой пояс/период; фильтры в отчёте; UTM потерялись; отложенные конверсии в окне атрибуции; CRM отбраковала лиды (спам, дубли). Норма расхождения кликов и визитов — примерно 5–15%; больше — искать техническую причину.

## 7. Стратегия «не держит» KPI

- Несколько целей с разным CPA → считать wtCPA и ожидаемый расход (`analysis/metrics.md`).
- Недельный бюджет ниже, чем нужно для 10 конверсий/нед → стратегия не обучится.
- Целевой CPA задан ниже рыночной цены конверсии → мало показов, а не «плохая стратегия».
- Частые правки (ставки, бюджет, семантика) сбивают обучение — считать «дни без правок».
- Разные модели атрибуции в стратегии и в отчёте → кажущееся расхождение.

## 8. Просадка после правок

Строить срез по дате и сопоставлять с журналом изменений кампании (`docs/campaigns/logs.md`). Оценивать эффект правки — не раньше, чем через период обучения + окно атрибуции.

## Когда вывод = «данных недостаточно»

Так и писать, плюс: какой период/цель/срез нужен, сколько ждать, какой объём кликов даст ответ. Ложный точный вывод хуже честного «пока не видно».
