# Какой отчёт строить под какой вопрос

Источники: `docs/statistics/report-wizard.md`, `docs/statistics/about.md` (новый Мастер отчётов), `docs/statistics/campaign-report.md`, `docs/statistics/search-queries.md`, `docs/statistics/library.md`.

## Где брать данные

1. **Мастер отчётов** — основной инструмент. Кампания → «Посмотреть статистику», или меню → Статистика → «Статистика по всем кампаниям». Задаётся: период (можно два периода A/B без пересечения, B раньше A), цель, атрибуция, срезы, столбцы, фильтры. Отчёты сохраняются (`docs/statistics/library.md`).
2. **Стандартные отчёты**: Общая статистика, Фразы по дням, По регионам, По площадкам; общий PDF по кампаниям (`docs/statistics/campaign-report.md`). Атрибуция не выбирается только в «Общей статистике».
3. **Вкладка «Поисковые запросы»** — реальные запросы, условие показа, категория таргетинга, тип соответствия; 180 дней.
4. **Метрика** — поведение на сайте, ассоциированные конверсии, кросс-канал, отчёт «Директ — расходы».
5. **XLS/Коммандер/API** — выгрузка структуры кампаний (что настроено), не статистики.
6. **Браузер** — если файла нет: снять таблицу через `mcp__Claude_Browser__*` (см. `../yandex-direct/action/browser-workflow.md`, только чтение).

**Что просить у пользователя**, если данных нет: выгрузку XLSX/CSV из Мастера отчётов с фиксированной парой (цель, атрибуция) и указанным периодом. Всегда указывать конкретные срезы и столбцы из таблицы ниже.

## Рецепты

Столбцы-минимум везде: Показы, Клики, CTR, Расход, Ср. цена клика, Конверсии, Конверсия (%), Цена цели. Плюс Доход/ДРР/ROI, если доход передаётся.

| Вопрос | Срезы | Дополнительно |
|--------|-------|----------------|
| Общая динамика | Дата (день/неделя) | график; сравнение периодов A/B |
| Где деньги в аккаунте | Кампания | сортировка по Расходу |
| Что внутри кампании | Группа, № объявления/баннера | сравнивать объявления в одной группе |
| Ключи-транжиры | Условие показа (фраза), Тип соответствия | фильтр: Расход > X И Конверсии = 0 |
| Мусорные запросы | вкладка «Поисковые запросы» (запрос, условие показа, категория таргетинга) | сортировка по Кликам; минус-фразы добавляются прямо из отчёта |
| Автотаргетинг vs фразы | Условие показа / Тип условия показа | отдельно оценить категории автотаргетинга |
| Плохие площадки РСЯ | Площадка (Название площадки), Тип площадки | автостратегии оптимизируют сами — ручное отключение по чуть-чуть вредно |
| Гео | Регион таргетинга / Регион местонахождения | база под корректировки по регионам |
| Устройства | Тип устройства | корректировки моб./десктоп |
| Время | День недели, Час | корректировки по времени; учитывать часовой пояс |
| Пол/возраст | Пол, Возраст | корректировки аудиторий |
| Поиск vs РСЯ | Тип площадки (Поиск/Сети) | разная логика оценки, не мешать в один вывод |
| Товарка/фид | Категория товаров, Оффер | `docs/statistics/report-wizard.md` (аналитика по категориям) |
| Эффект медийки | атрибуция «Первый/Последний показ из Директа кросс-девайс» + окно | только Мастер отчётов; плюс Brand/Search/Visit Lift |
| Отложенные конверсии | сравнить «Последний значимый» vs «Первый переход» | разрыв = длинный цикл сделки |
| Проверка стратегии по нескольким целям | Кампания + метрики суммарно по всем целям | wtCPA, см. `analysis/metrics.md` |
| Эксперимент A/B | Кампания (обе ветки эксперимента), Дата | `docs/campaigns/experiments.md` |

## Гигиена отчёта

- Один отчёт — одна пара (цель, атрибуция). Меняешь пару — это уже другой отчёт, старые выводы не переносятся.
- Период сравнения: равной длины, без пересечения, с поправкой на праздники/сезон и на дни недели (28 дней лучше, чем «месяц»).
- Свежие дни недостоверны: конверсии дозаписываются, часть визитов ещё в окне атрибуции. Последние 1–3 дня в сравнение не брать.
- Разбивка по дате + мелкий срез = строки по 2 клика. Дробить только после того, как найдено крупное.
- UTM-метки нужны для сверки с Метрикой/CRM (`docs/statistics/url-tags.md`); расхождение Директ vs Метрика по кликам/визитам в 5–15% — норма (роботы, отказ от загрузки счётчика, редиректы).
- Экспорт: XLSX/CSV. Для парсинга удобнее CSV/TSV (`analysis/data-processing.md`).
