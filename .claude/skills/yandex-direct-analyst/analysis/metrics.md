# Метрики и формулы

Источники: `docs/statistics/performance-stat-guide.md`, `docs/statistics/profit-and-value.md`, `docs/statistics/multiple-goals-strategy.md`, `docs/glossary.md`.

## Базовые

| Метрика | Формула | Смысл |
|---------|---------|-------|
| CTR | клики / показы | кликабельность; на Поиске — сигнал релевантности, в РСЯ почти не показатель качества |
| CPC (средняя цена клика) | расход / клики | |
| CPM | расход / показы × 1000 | медийка |
| CR, Конверсия (%) | конверсии / клики (визиты) × 100 | доля целевых визитов |
| CPA, Цена цели | расход / конверсии | средние затраты на конверсию |
| Доход | сумма ценности достигнутых целей, переданная в Директ | считается по целям из «Настройка метрики Доход» |
| ДРР | расход / доход × 100 | доля рекламных расходов |
| ROAS | доход / расход × 100 | обратная ДРР |
| ROI (в Директе) | (доход − расход) / расход × 100 | производная от «Дохода» |
| Маржинальный ROI (свой расчёт) | (доход × маржа − расход) / расход × 100 | честная окупаемость, если известна маржа |
| Прибыль | доход − расход (по данным Директа) | без себестоимости товара |
| Доля показов (IS) | показы / возможные показы | сколько аукциона забрали |

Производные метрики (ДРР, ROI, прибыль) в Директе считаются от метрики «Доход» — она рассчитывается только по целям, по которым доход реально передаётся (Ecommerce, JS-события, офлайн-конверсии). Если доход не передаётся, а ценность задана вручную в стратегии — работают аналоги «по ценности» (`docs/statistics/profit-and-value.md`).

Без целей Метрики доступны только вовлечённые сессии: **Сумма ВС, Цена ВС, Доля ВС (%)** — машинная оценка заинтересованности (`docs/statistics/report-wizard-engagement-rating.md`). Это костыль, а не замена целям.

## Декомпозиция (куда смотреть при просадке)

```
Конверсии = Показы × CTR × CR
Расход    = Показы × CTR × CPC
CPA       = CPC / CR
Доход     = Конверсии × средний чек
ДРР       = CPA / средний чек   (при CR, посчитанной по той же цели)
```

Правило: **CPA вырос → либо CPC вырос, либо CR упал.** Сначала определить какой из двух, потом искать причину только в нём. Дальше — по срезам: где именно (кампания, фраза, площадка, гео, устройство, время, аудитория).

## Статистическая значимость

Из `docs/statistics/performance-stat-guide.md` — относительная погрешность при доверии 68%:

| Конверсии | Погрешность Конверсии (%) | Погрешность Цены конверсии |
|-----------|---------------------------|----------------------------|
| 25 | ± 20% | ± 40% |
| 100 | ± 10% | ± 20% |
| 400 | ± 5% | ± 10% |
| 2500 | ± 2% | ± 4% |

Следствия:
- Уменьшить погрешность вдвое — нужно вчетверо больше конверсий.
- Различие двух срезов меньше погрешности → **вывод делать нельзя**, писать «разница в пределах погрешности».
- Мало конверсий → расширить период или взять цель выше по воронке (микроконверсия).
- Для решения «отключить фразу/площадку» ориентир: набрано кликов ≥ 3 × (1 / ожидаемый CR). Например, при типичном CR 2% — ~150 кликов без конверсии, прежде чем говорить «не работает». Меньше — это шум, а не приговор.

Быстрая проверка A/B двух вариантов (доли конверсии) — z-тест, `analysis/data-processing.md`.

## Оценка автостратегии

- **Расход выше планового без правок — не обязательно сбой.** Две штатные механики (подробнее — `../yandex-direct/updates/2026-08-strategii-i-byudzhety.md`):
  - **перенос остатка**: неизрасходованное с прошлой недели, до 30% недельного бюджета, потолок недели — 130% планового; остатки не накапливаются. Оценивать накопительным итогом от недели недотраты.
  - **адаптация бюджета**: +10% или +20% к бюджету следующей недели, если за прошлую израсходовано >90% бюджета, факт CPA/ДРР не выше целевого и не было рестарта. Эффект накопительный.
  Прежде чем писать «бюджет разогнали вручную», проверить обе настройки и журнал изменений.
- **Оплата за конверсии**: списываются только конверсии в течение 21 дня с клика; расход относится к дню **клика** (в Метрике — к дню конверсии). Дневные ряды двух систем из-за этого не совпадают.
- **Обучение**: нужно ~10 конверсий в неделю на кампанию; в период обучения (обычно 7–14 дней) метрики нестабильны, правки сбивают обучение. Судить об эффекте — после.
- **Несколько целей с разным CPA** (`docs/statistics/multiple-goals-strategy.md`): делить расход на конверсии одной цели — искажение. Считать средневзвешенный целевой CPA:

  ```
  wtCPA = Σ(целевой CPA_i × конверсии_i) / Σ(конверсии_i)
  ```
  Фактический CPA = расход / Σ конверсий по всем целям. Факт < wtCPA → стратегия в ограничениях.
- Альтернатива: **ожидаемый расход** = Σ(конверсии_i × целевой CPA_i). Факт < ожидаемого → укладывается. В Мастере отчётов для «Максимума конверсий» метрика «Ценность конверсий» и есть ожидаемый расход — сравнивать её с фактическим расходом.
- Корректировки ставок влияют на фактический CPA — учитывать при сравнении.
- Оплата за конверсии: сверять, за какие визиты платим — зависит от модели атрибуции (`docs/statistics/attribution-model.md`).

## Модели атрибуции (влияют на все конверсионные цифры)

| Модель | Окно | Когда брать |
|--------|------|-------------|
| Автоматическая | ML | оценка вклада именно Директа; обучение стратегий |
| Первый переход | 180 дн | отложенный спрос, длинный цикл сделки; узнаваемый бренд |
| Последний переход | 180 дн | технический анализ сайта |
| Последний значимый переход | 90 дн | какой канал стал решающим стимулом |
| Последний переход из Директа | 180 дн | все визиты, связанные с Директом |
| Первый/Последний показ из Директа кросс-девайс | окно 1/3/7/14/21/30 дн | вклад медийки; только Мастер отчётов |

Правила: сравнивать периоды и срезы только в одной модели; расхождение Директ vs Метрика чаще всего = разные модели/цели/часовые пояса/фильтры роботов. Статистика по автоматической атрибуции — по визитам с 08.04.2023.

## Горизонты данных

- Статистика Директа — за последние **3 года** от текущего месяца.
- Отчёт «Поисковые запросы» — **180 дней**.
- Строка «Другие поисковые запросы» — необработанные (<1 часа) и малозначимые запросы; в анализ долей не включать как отдельный источник.

## Ориентиры (не нормативы Яндекса — рабочие эвристики)

- Поиск: CTR ниже ~5% на брендовых запросах — почти всегда проблема объявления/позиции; в РСЯ нормальный CTR — доли процента.
- Доля брендового трафика: считать отдельно, иначе бренд маскирует убыточность небренда.
- Отказы (Метрика) выше ~30–40% на Поиске при релевантной посадочной — смотреть скорость сайта и соответствие запроса странице.
- Строки с расходом, но 0 конверсий, набравшие статзначимый объём кликов, — первый кандидат на отключение/минусовку.
- Топ-20% срезов обычно дают 80% расхода — начинать разбор с них, а не с длинного хвоста.
