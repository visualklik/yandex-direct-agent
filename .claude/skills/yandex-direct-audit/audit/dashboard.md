# Визуальный отчёт аудита: принципы вёрстки

Генератор — `dashboard.py`. Один самодостаточный HTML: ни шрифтов, ни библиотек, ни запросов
наружу. Файл можно переслать в мессенджере, открыть офлайн и распечатать в PDF.

```bash
python3 dashboard.py --snapshot snapshot.json \
    --campaigns camp.tsv --placements placements.tsv --days days.tsv \
    --target-cpa 500 --account "Клиент" --period "20.07 — 18.08.2026" \
    --out audit.html
```

Обязателен только `--snapshot`. Отчётов нет — соответствующие блоки не рисуются, а не заполняются
заглушками. `--anonymize` заменяет названия кампаний на «Кампания N» — для демонстраций и портфолио.

## Порядок блоков — от решения к данным

Типовая ошибка отчётов: инвентаризация сверху, план правок в самом низу. Читатель прокручивает
восемь таблиц, прежде чем узнает, что ему делать. Здесь наоборот:

1. **Вердикт** — оценка 0–100, одна фраза о состоянии аккаунта, 4 строки сути, KPI-полоса.
2. **Что делать первым** — план правок сразу, карточками P0/P1/P2, с ожидаемым эффектом справа.
3. **Где деньги** — расход по кампаниям, доля Поиск/Сети, динамика по дням.
4. **Площадки РСЯ** — кривая концентрации, порог значимости, вердикт, список кандидатов.
5. **Настройки** — слепок значений таблицей.

Правило: чем ниже блок, тем он подробнее и тем менее обязателен для прочтения. Сырые таблицы
спрятаны в `<details>` — топ виден сразу, хвост по клику.

## Оценка аккаунта

Балл считается от находок: критичная −14, важная −6, улучшение −2, пол ограничен снизу пятёркой.
Это не научная метрика, а якорь для разговора: «58 из 100» запоминается и обсуждается,
а список из девяти пунктов — нет. Формулировка рядом обязательна: «здоровый» (80+),
«рабочий, но с потерями» (55–79), «требует вмешательства» (ниже).

## Графика — только та, что несёт вывод

Четыре типа, все — inline SVG или CSS, без библиотек:

| Элемент | Что показывает | Зачем |
|---|---|---|
| Горизонтальные бары | расход по кампаниям, подпись — CPA | видно и объём, и качество одновременно |
| Кольцо | Поиск против сетей | одна цифра, которую все спрашивают первой |
| Спарклайн | расход по дням линией, конверсии столбиками | расхождение форм = повод копать |
| Кривая концентрации | накопленная доля расхода по площадкам | доказывает, что чистить надо верх списка, а не хвост |

Чего сознательно нет: круговых диаграмм на 12 сегментов, 3D, градиентных заливок данных,
цветового кодирования там, где хватает порядка строк.

## Цвет как значение, а не как украшение

Три семантических цвета и ничего сверх: P0 — красный, P1 — янтарный, P2 — синий, норма — бирюзовый
акцент. Красный не используется для оформления заголовков, янтарный — для «просто важно».
Если элемент цветной, у цвета есть смысл, который читается из легенды или тега рядом.

Тема следует системной: полная палитра в `:root`, переопределение в
`@media (prefers-color-scheme: dark)` под `:root:not([data-theme="light"])`. Фон `body` задан
токеном явно — иначе страница на тёмной теме просвечивает.

## Печать

`@media print` убирает навигацию, раскрывает `<details>`, снимает тени и запрещает разрыв секций.
PDF снимается так:

```bash
chromium --headless --disable-gpu --no-sandbox \
  --print-to-pdf=audit.pdf --no-pdf-header-footer audit.html
```

## Тексты

- Заголовок блока — что это. Подзаголовок (`.lede`) — как читать график. Без подзаголовка
  диаграмма превращается в украшение.
- Каждая находка: что не так → где (объекты) → эффект правки. Три части, ни одной лишней.
- Вывод пишется словами даже там, где он отрицательный: «кандидатов на запрет нет, хвост —
  статистический шум» полезнее пустой таблицы.
- Числа с неразрывными пробелами, проценты до одного знака, деньги без копеек.
- Склонения считаются (`plural()`), «1 находки» в отчёте для клиента недопустимо.

## Что можно добавить под конкретный проект

Блоки, которые генератор пока не рисует, но данные для них снимаются тем же способом:
поисковые запросы (топ по расходу с пометкой мусорных), гео-хвост, устройства,
объявления с битыми ссылками, история изменений. Добавлять по одному и только если
у блока есть вывод — иначе отчёт распухает и его перестают читать.
