# Комплаенс: маркировка и модерация

Раздел про то, за что штрафуют, а не про то, что просто неэффективно. Проверяется частично
автоматически, частично глазами: API отдаёт статусы модерации и поля ЕРИР, но не содержание
сайта и не документы рекламодателя.

Первоисточник по модерации — `docs/moderation/` в базе справки (в том числе
`docs/moderation/restricted-categories.md` и разбор по категориям в `docs/moderation/categories/`).
Здесь только то, что нужно проверить на аудите, и как это увидеть.

## Маркировка рекламы и ЕРИР

С сентября 2022 интернет-реклама в России маркируется, данные передаются в ЕРИР через ОРД,
у креатива есть идентификатор `erid`. Директ передаёт данные сам, но проверить стоит:

| Что | Где смотреть |
|---|---|
| Описание объявления для ЕРИР | поле `ErirAdDescription` в `ResponsiveAd` / `TextAd` |
| Автоматически сгенерированное описание | `AutogeneratedErirAdDescription` (только чтение) |
| Данные рекламодателя | карточка клиента: ИНН, наименование |

Пустое `ErirAdDescription` при заполненном `Autogenerated…` — не нарушение: Директ подставил
описание сам. Тревожный случай — когда нет ни того, ни другого.

## Статусы модерации

| Проверка | Как увидеть |
|---|---|
| Отклонённые объявления | `Status = REJECTED` в `ads.get` — автопроверка `AD01` |
| Причина отклонения | `StatusClarification` — текст от модератора |
| Отклонённые расширения | `SitelinksModeration`, `DisplayUrlPathModeration`, `ButtonExtensionModeration`, `VCardModeration` |
| Кампания на модерации | `Status = MODERATION` при `State = ON` — показов нет |

Отклонённое расширение — частый тихий случай: объявление работает, а быстрые ссылки или визитка
не показываются, и никто этого не замечает.

## Тематики, требующие документов

Проверяется вручную: сверить тематику сайта со списком. Для перечисленных нужны лицензия
и дисклеймер в объявлении или на посадочной.

| Тематика | Что требуется |
|---|---|
| Медицинские услуги, клиники | лицензия, предупреждение о противопоказаниях |
| Лекарства | рецептурные — запрет; безрецептурные — дисклеймер |
| БАДы | «Не является лекарственным средством» |
| Финансовые услуги, кредиты, МФО | лицензия ЦБ, полные условия |
| Страхование | лицензия, условия |
| Образование | лицензия на образовательную деятельность |
| Строительство | членство в СРО для отдельных работ |
| Алкоголь, табак, азартные игры | запреты и жёсткие ограничения — см. `docs/moderation/` |

## Требования к текстам

Проверяется чтением выборки объявлений:

- нет CAPS LOCK, кроме аббревиатур;
- нет превосходных степеней без подтверждения («лучший», «№1», «самый»);
- нет контактов (телефон, почта) в тексте объявления — для этого визитка;
- нет гарантий результата в медицине и финансах;
- цена в объявлении совпадает с ценой на посадочной.

## Посадочные страницы

- страница доступна — автопроверка `urls.py`;
- содержание соответствует объявлению;
- при сборе персональных данных есть политика конфиденциальности и согласие;
- для коммерческого сайта указаны ИНН и реквизиты;
- нет автоматических скачиваний.

## Чеклист для отчёта

1. ☐ Отклонённых объявлений нет (`AD01`)
2. ☐ Расширения прошли модерацию (`SitelinksModeration` и прочие)
3. ☐ `ErirAdDescription` заполнено или сгенерировано автоматически
4. ☐ Реквизиты рекламодателя в аккаунте указаны
5. ☐ Для лицензируемой тематики документы загружены
6. ☐ Дисклеймеры на месте
7. ☐ В текстах нет запрещённых формулировок
8. ☐ Посадочные доступны и релевантны (`urls.py`)
9. ☐ Политика конфиденциальности на страницах с формами

Пункты 4–7 и 9 — ручные: из API их не видно. В отчёте помечать «не проверено», а не «в порядке».
