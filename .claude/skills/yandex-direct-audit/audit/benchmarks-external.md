# Внешние бенчмарки по тематикам

Цифры взяты из чужого скилла целиком и **источника не имеют**: ни ссылки на исследование,
ни описания выборки, ни периода. Держим их как грубый ориентир для разговора с клиентом
(«ваш CPC 180 ₽ — для юруслуг это середина диапазона»), но ни одна правка не должна опираться
на них как на факт.

**Правило скилла остаётся прежним: норма считается по самому аккаунту.** Медиана собственных
дневных рядов и собственный CPA против KPI бизнеса — вот основание для решений. Чужая средняя
по нише не знает ни вашего оффера, ни сезона, ни региона, ни аукциона в вашем городе.

## Как этим пользоваться

Можно: назвать порядок величины, если у клиента нет вообще никакой точки отсчёта; проверить
собственную гипотезу на вменяемость.

Нельзя: писать в отчёт «CTR ниже нормы по рынку, надо переписать объявления»; ставить целевой
CPA по таблице; сравнивать аккаунты клиентов между собой через эти диапазоны.

В отчёте, если цифры всё же приводятся, обязательна пометка об источнике — иначе читатель
примет их за факт, а они им не являются.
