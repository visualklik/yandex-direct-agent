# Генерация XLS/XLSX для массовой загрузки

Основной метод создания кампаний (надёжнее браузера). Собираю файл → пользователь грузит в Директ. Полные детали формата и ошибок — `docs/alternative-interfaces/xls-interface.md`, `docs/alternative-interfaces/xls-interface-errors.md`. Десктоп-альтернатива — `docs/alternative-interfaces/direct-commander.md`.

## Шаблон

Официальный: https://doc-static.yandex.net/src/support/direct/ru/files/direct_example.xlsx
Вкладки: «Тексты» (редактируем), «Регионы» (справочник кодов), «Словарь значений полей» (типы кампаний/объявлений — только читаем).

## Ключевые поля «Тексты»

| Поле | Обяз. | Лимит/примечание |
|------|-------|------------------|
| Тип кампании | при создании | из «Словаря значений» |
| Название группы | да | |
| Заголовок 1–7 | 1-й да | ≤ 56, слово ≤ 22 |
| Текст 1–3 | 1-й да | ≤ 81, слово ≤ 23 |
| Ссылка | да | с протоколом, ≤ 1024 |
| Ключевые фразы | — | ≤ 200 на группу, ≤ 7 слов |
| Минус-фразы | — | кампания ≤ 20000 симв., группа ≤ 4096 |
| Ставка Поиск / Сети | — | ручные стратегии |
| Регион | — | коды из вкладки «Регионы» |
| Быстрые ссылки | — | заголовок ≤ 30, описание ≤ 60 |
| Уточнения | — | ≤ 25 знаков каждое |
| ID изображения / ID видео | — | |
| Метки | — | аналитика/группировка |

Актуальные лимиты сверять с `docs/moderation/technical-restrictions.md`.

## Ограничения файла

- Макс. **60 000 строк**. Только XLS/XLSX (не XLSM/XLSB).

## Процесс

Выгрузка: Инструменты → «Управление с помощью Excel» → кампания → формат.
Загрузка — 3 режима: «Изменить кампанию» / «Создать новую» / «Добавить в существующую». Кампания блокируется ~5 мин.

## Предупреждения

- ⚠️ При копировании через XLS **стратегия не сохраняется** → ставится «Максимум кликов». После загрузки выставить нужную в интерфейсе.
- ⚠️ Удаление ID объявления из файла → старое удаляется, создаётся новое.
- Ошибки в файле → данные НЕ загружаются, показ сообщения.

## Баллы (лимит операций)

Списываются при успешном импорте: новое объявление 12, редакт. объявления 4, новая фраза 2, редакт. фразы 1.

## Как генерирую

1. Читаю структуру шаблона (или `docs/alternative-interfaces/xls-interface.md`).
2. Раскладываю по строкам: строка = объявление + фраза/группа.
3. Проверяю ВСЕ лимиты до записи.
4. Пишу .xlsx (Python: openpyxl) в папку проекта.
5. Отдаю файл + инструкцию загрузки.
6. Напоминаю проверить стратегию после импорта.
