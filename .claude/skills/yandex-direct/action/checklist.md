# Чеклист перед запуском и при оптимизации

Полная версия — `docs/efficiency/check-list.md`. Ниже рабочий минимум.

## Перед запуском

- [ ] Счётчик Метрики на всех страницах сайта.
- [ ] Цели настроены; автоцели вкл.; коллтрекинг для звонков.
- [ ] Ключевые фразы покрывают важные запросы.
- [ ] Минус-слова собраны, не режут ценные запросы.
- [ ] Автотаргетинг вкл. (ЕПК — обязателен, ≥1 категория).
- [ ] Гео верное.
- [ ] Стратегия под цель; ставки/цели адекватны.
- [ ] Бюджет на обучение (~10 конверсий/нед).
- [ ] Расписание не ограничено без нужды.
- [ ] Ссылки рабочие, на релевантные посадочные, с UTM.
- [ ] Тексты/картинки в лимитах, пройдут модерацию.
- [ ] Регулируемая тематика — документы/лицензии есть.

## Мало конверсий

Расширить ключи, вкл. автотаргетинг + ретаргетинг + интересы; убрать лишние спецоператоры; тестировать форматы; конкретика вместо общих фраз; проверить цели в Метрике.

## Дорогие конверсии / высокий расход

Мастер кампаний; отчёт «Поисковые запросы» → уточнить операторами + минус-фразы; отключить неэффективные условия; релевантность посадочных; запрещённые площадки РСЯ.

## Плохой трафик / отказы

То же + оплата за конверсии вместо кликов; оптимизация сайта (скорость, моб., простые формы, видимые контакты).

## Не прошла модерация

Изменить текст/креативы; загрузить документы; проверить правила категории (`docs/moderation/categories/`); клиентский сервис.
