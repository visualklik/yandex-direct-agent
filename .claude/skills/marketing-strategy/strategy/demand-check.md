# Спрос: тип и проверка фактами

Тип спроса определяет всё дальнейшее — каналы, тексты, бюджет и сроки. Ошибка здесь стоит
дороже любой другой: под отложенный спрос запускают Поиск с прямыми запросами, получают
дорогие клики без заявок и делают вывод, что «реклама не работает».

## Три типа

| Тип | Признак | Как выглядит в рекламе |
|---|---|---|
| **Срочный** | человек уже ищет решение: «купить», «заказать», «цена», «рядом» | Поиск, максимум релевантности, конверсия быстрая |
| **Отложенный** | ищет информацию, сравнивает, решение зреет месяцами (дом, авто, обучение) | Поиск по широким запросам + сети, прогрев, ретаргетинг, длинное окно атрибуции |
| **Формируемый** | человек не знает, что такое решение существует | Сети и контент, спрос создаётся, а не собирается; Поиск почти бесполезен |

Один продукт может иметь все три слоя одновременно. Смысл шага — понять, **какой слой мы
покупаем на старте** и на какой бюджет рассчитываем.

## Проверка фактами

Догадки о спросе проверяются за минуту: API Директа отвечает, есть ли у фразы показы
в регионе.

```bash
set -a && . ./.env && set +a
python3 strategy/demand_probe.py --themes themes.txt --geo 213 --out demand.json
```

`themes.txt` — темы по одной в строке, каждая с вариантами через `|`:

```
купить <продукт>|заказать <продукт>|<продукт> цена
<продукт> отзывы|<продукт> сравнение|какой <продукт> выбрать
<проблема> что делать|как решить <проблема>
```

Скрипт вернёт по каждой теме долю фраз со спросом. Читается так:

- **транзакционные темы живые** → есть срочный спрос, Поиск оправдан;
- **живут только информационные** → спрос отложенный, на Поиске собираем читателей,
  а не покупателей; нужен прогрев и длинный горизонт оценки;
- **не живёт почти ничего** → спрос формируемый. Поиск не спасёт, разговор о сетях,
  контенте и о том, что первые месяцы — это инвестиция, а не окупаемость.

## Чего проверка не даёт

`hasSearchVolume` отвечает «есть / нет», но не «сколько». Объём оценивается прогнозом бюджета
в интерфейсе Директа. Поэтому вывод формулируется как «спрос есть, порядок неизвестен»,
а не «в месяц будет N заявок».

## Артефакт

`demand.json` — темы, живые и мёртвые фразы, доля; плюс абзац в стратегию: какой тип спроса
и почему. Живые фразы дальше идут прямо в семантику — это тот же формат, который читает
`keyword_volume.py` из скилла `yandex-direct`.
