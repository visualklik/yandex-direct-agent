# Передача: из стратегии в кампании

Стратегия заканчивается не документом, а тем, что исполняющий скилл получает вход и не
переизобретает решения заново.

## Что передаём

| Артефакт | Кто читает | Зачем |
|---|---|---|
| `brief.md` | `yandex-direct` | гео, бюджет, ограничения, экономика |
| `demand.json` | `yandex-direct` | фразы с подтверждённым спросом — основа семантики |
| `personas.md` | `yandex-direct` | язык объявлений, возражения → уточнения и быстрые ссылки |
| `usp.json` | `yandex-direct` | главное обещание в заголовки, довески не идут никуда |
| `channels.md` | человек | какие кампании вообще заводим |
| `budget.md` | `yandex-direct` | недельные бюджеты и выбор стратегии ставок |
| `kpi.md` | `yandex-direct-analyst` | что считать после запуска и по каким порогам |

## Порядок

1. Показать сводку стратегии: тип спроса, персоны, УТП, топ-3 канала, бюджет по фазам,
   главные KPI. Пять-семь строк, без пересказа файлов.
2. Спросить, с какого канала начинаем.
3. **Дождаться явного выбора.** Стратег кампании не создаёт и бюджеты не тратит.
4. По выбору — вызвать исполняющий скилл, передав пути к артефактам.

Для Директа дальше работает `../../yandex-direct/action/campaign-from-site.md`: разбор сайта,
семантика от `demand.json`, тексты из `usp.json` и `personas.md`, валидатор, XLSX.
Публикацию делает человек.

## Что переизобретать нельзя

Исполняющий скилл не переписывает бриф, не выдумывает новое УТП и не добавляет каналы
«заодно». Если на этапе сборки выясняется, что решение стратегии не работает — например,
под кластер нет посадочной, — это повод вернуться на соответствующий шаг стратегии,
а не чинить молча.

## Обратная связь

Через 3–4 недели после запуска стратегия проверяется фактами: `yandex-direct-analyst` считает
метрики по `kpi.md`, `yandex-direct-audit` смотрит настройки и аномалии. Результат —
не «отчёт», а решение по фазе: переходим к оптимизации, меняем канал или пересобираем гипотезу.

Гипотеза, которую не проверили цифрами через месяц, перестаёт быть гипотезой и становится
верой. Дата следующей сверки фиксируется прямо в стратегии.
