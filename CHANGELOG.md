# Изменения

## Август 2026 — стратег, аудитор и конвейер кампаний

### Новое

**Скилл `marketing-strategy`** — стратегический слой перед открытием кабинета. Девять шагов
с подтверждением: бриф, спрос, конкуренты, персоны, УТП, каналы, бюджет, KPI, передача.
Скрипты: `demand_probe.py` (проверка спроса через API), `competitor_scan.py` (сканирование
сайтов конкурентов), `report.py` (HTML-отчёт). Субагент `marketing-strategist`.

**Конвейер «сайт → кампания»** в скилле `yandex-direct`: `site_scan.py` разбирает сайт,
`keyword_volume.py` отсеивает фразы без спроса, `adtext_check.py` проверяет лимиты и правила
модерации, `xls_build.py` собирает лист «Тексты» для загрузки.

**Справочник по креативам сетей** `action/rsya-creatives.md` — размеры и соотношения
изображений, смарт-центры, требования модерации, видео; каждая цифра со ссылкой на статью
справки.

**Организация проектов:** одна папка на клиента `projects/<slug>/` с подкаталогами
`strategy`, `campaigns`, `audit`, `data`. Каталог в `.gitignore`.

### Аудитор

- `checks.py` переписан на реестр проверок: идентификатор, категория, серьёзность, признак
  быстрой починки; статусы pass / warn / fail / na.
- Балл с весами категорий и грейдом A–F; неприменимые проверки исключаются из знаменателя
  (`scoring.md`).
- Новые проверки: продуктивность фраз, размер групп, кампании-зомби, число быстрых ссылок,
  библиотечные наборы минус-слов, единая атрибуция, корректировки ставок, дополнительные
  релевантные фразы, широкоформатные изображения.
- `compliance.md` — маркировка рекламы и ЕРИР, статусы модерации расширений, тематики
  с ограничениями; всё по справке.
- `anomalies.py` — каталог из десяти правил, норма считается робастно (медиана и MAD).
  Полоса без конверсий проверяется на ожидаемое число, иначе кампании с редкими конверсиями
  дают ложные срабатывания.
- `urls.py` — доступность посадочных и быстрых ссылок: коды ответа, редирект на главную,
  мягкие 404.
- `fetch.py` — все отчёты одной командой, включая срезы по типу таргетинга, типу соответствия,
  объёму трафика, бренду в запросе.
- Дашборд: срезы эффективности, топ поисковых запросов, аномальные дни, посадочные, быстрые
  победы, покрытие проверок.

### Исправленные ошибки

- Ложные срабатывания проверок: цель конверсионной стратегии лежит в `BiddingStrategy.*.GoalId`,
  а не только в `PriorityGoals`; минус-слова живут на трёх уровнях; клоны объявлений считаются
  внутри одной посадочной; изображения проверяются только у кампаний с показами в сетях.
- Быстрые ссылки в XLS хранятся в трёх колонках с разделителем `||`, а не отдельными
  колонками на каждую; поддержано восемь ссылок с описаниями.
- Правило проекта: отображаемая ссылка не заполняется.
